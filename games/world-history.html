True History Atlas

An interactive world-history map experience — not a traditional game, more of a bonus exploration prototype for browsing historical events and periods on a real map.

Launch Experience Back to Arcade

Build Info

Version: internally labeled "True History Atlas — Friend Test Benchmark"
Status: Experimental build (bonus prototype)
Platform: Browser / HTML (Leaflet map library from a CDN, plus live map-tile, historical-boundary, and Wikipedia-summary data fetched at runtime)

Controls

  • Mouse or touch: pan and zoom the map
  • Click/tap: explore markers and events

Known Notes

  • Experimental prototype — provisional, not a finished build
  • Bonus/secondary item, not one of the original three arcade launch titles
  • Requires an internet connection — this build loads the Leaflet map library, map tiles, historical boundary data (GitHub-hosted GeoJSON), and event-summary text/thumbnails (Wikipedia's public API) live over the network

This experience needs internet access — it loads its map library, map tiles, boundary data, and Wikipedia summaries live and will not fully work offline.
